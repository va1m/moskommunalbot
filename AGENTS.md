# Project architecture

Java 17/Maven Telegram bot using TelegramBots, Dagger DI, Lombok, SQLite JDBC/HikariCP and SLF4J/Logback. Under `src/main/java/com/va1m/moskommunalbot/`: `Main` boots `MosKommunalBot` via `BotFactory`; `interaction/` manages chat state/persistence; its `stateprocessors/` validates readings and calculates results; `model/` holds data; `priceproviders/` holds dated tariffs. SQL: `src/main/sql/`; logging: `src/main/resources/`. Tests in `src/test/` use JUnit Jupiter, Mockito and AssertJ. `pom.xml` builds a shaded JAR (`mvn clean verify`). Configuration: `token` and `dburl` JVM properties.
